# NEXUS · Reloj orbital

Abrí `dist/index.html` con doble clic. No requiere instalar nada ni conexión a internet.

- Hora y fecha del dispositivo, con segundos en vivo.
- Selector de 12/24 horas; recuerda el formato elegido cuando el navegador lo permite.
- Anillos, partículas y señales animadas, con botón para pausarlas.
- Pantalla completa desde el botón o con F11; Esc para salir.
- Respeta la preferencia del sistema de reducir movimiento al iniciar.

La imagen de referencia está copiada en `dist/assets/ciudad.png`. El panel central cubre la hora impresa en la imagen y muestra dígitos SVG dinámicos.
